# Digital Image Processing Using MATLAB Projects - Chapter 3 Solutions

All projects in Chapter 3 have been solved using a personal portrait instead of the referenced .tif images from the DIPUMe3 support package, which is not freely available.

## Overview

- The solutions provided include techniques like histogram equalization, local histogram equalization, and histogram specification.
- Each technique was demonstrated using a personal portrait to replicate the expected outcomes of the projects.
- The MATLAB or Python code for each project has been adjusted to work with any given image.

## Order of Projects

The order of the projects is documented by the naming convention used for the source code and output files. Each source code file is named in the format 'P3_i.m' or 'P3_i.py' where 'i' corresponds to the specific project number. Similarly, output files are named in the format '3_i_j.png' for images and '3_i_j.fig' for MATLAB figures, where 'i' is the project number and 'j' differentiates between multiple outputs from the same project.

## Note for Usage

To run the projects with your own images:
- Replace the 'input.tif' or any book reference image in the code with the path to your image file.
- Ensure that your image file is accessible at the specified path in the MATLAB or Python environment.

## Disclaimer

The solutions are provided for educational purposes only. If you are using personal portraits, ensure you have the rights or consent to use those images for processing and demonstration.
